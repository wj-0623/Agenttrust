# AgentTrust 个人使用指南（v1.0.0）

## 项目边界

AgentTrust 是独立的 Agent 安全与评测作品，不读取、不写入也不要求修改星限。两个项目只在简历中形成能力互补：星限展示 Agent 应用和产品交付，AgentTrust 展示安全控制面、评测、可观测性和发布治理。任何运行时集成都不是个人展示的前置条件。

`/api/v1/guard/check` 可由任意受信 Agent Adapter 在输入、外部上下文、工具执行前、工具结果和最终输出五个边界调用。上下文和工具结果默认被标记为不可信来源；会话接触敏感来源后再调用出站工具会被阻断。Guard 的审批结果不是执行凭证，副作用仍必须使用参数绑定的一次性 Capability Lease。

本项目用于个人维护 Agent、合成数据攻防实验和作品展示。默认使用 SQLite、内置模拟工具和人工审核策略发布，不要求 PostgreSQL、Temporal、OIDC 或 Phoenix。原有企业集成保留为可选实验功能，未据此声明生产可用。

## 启动

在 backend 下激活现有 .venv，执行 `pip install -r requirements-dev.txt`。新增依赖为 jsonschema 和 regex，分别提供工具参数校验和正则执行超时。

执行 `python -m uvicorn app.main:app --host 127.0.0.1 --port 8010`。前端可在 frontend 下执行 `npm run dev`，默认也只监听 127.0.0.1。不要把无认证模式通过反向代理或端口映射公开；该模式检查连接来源、Host 和浏览器 Origin。需要远程使用时启用认证并配置 TLS，不应关闭这些检查。

也可先在 frontend 执行 `npm run build`，再只启动后端，通过 http://127.0.0.1:8010 使用同源页面。构建保留已有旧资源文件，不自动清空 dist。

## 日常维护流程

1. 在调试台运行正常任务，检查 Trace；演示模型不会真正执行工具，工具执行应使用持久执行页面。
2. 运行单轮／多轮红队扫描，查看轮次、费用上限、停止原因和实验清单。默认不会自动发布，也不会自动启动真实流量灰度。
3. 在自动纠错页查看候选增量、回放通过率和失败，再点击“审核并发布此策略”。后端再次检查主集、合成 holdout 和该项目自定义数据集，拒绝新增回归、放宽现有规则或改动受保护字段。
4. 如果基线策略已经变化，旧候选会拒绝发布。重新生成并审核，不能覆盖较新的人工修改。
5. 已发布候选可以回滚。回滚创建新策略版本，并拒绝覆盖更新的人工版本。

`AGENTTRUST_CORRECTION_AUTO_PROMOTE_DEVELOPMENT=false` 是默认值。保留的自动晋级模式仅用于显式启用的实验；不建议个人日常使用。`auto_correct` 控制候选生成，并不意味着已经批准部署。

## 可选外部 Agent 黑盒演示

通用 `external_agent` 适配器默认禁用出站目标。确需演示时，先把一个经过审查的完整 HTTPS URL 加入 `AGENTTRUST_EXTERNAL_AGENT_ENDPOINT_ALLOWLIST`，再运行历史兼容脚本 `examples/nexus_integration.py --target-url <URL>`。该脚本只在 AgentTrust 中创建项目并调用目标 API，不修改目标仓库、配置或数据。

外层代理只能检查调用前输入和调用后返回，不能撤销上游已经发生的副作用。因此只应连接无副作用的演示目标；写文件、发消息、付款或设备控制必须在目标执行前接入 Guard 与 Capability Lease。生产模式还要求服务端 Bearer Token，令牌只从环境变量读取，不存入项目表。

## 来源图与实验凭证

- 每个 Guard 响应包含 `provenance_id`、父 Guard、会话标签与 `sequence_risk`；查询 `/api/v1/guard/sessions/{session_id}/provenance` 可回放脱敏来源图。
- 来源图只保存内容 SHA-256、标签和决策，不保存原始提示词、工具结果或参数。超过 500 个节点的会话应由接入端开始新会话。
- 红队与评测响应包含 `agenttrust.run-manifest.v1`，记录策略、数据集、结果、模型、构建版本、随机种子和运行配置哈希。
- 使用 `GET /api/v1/evaluations/compare/runs` 比较两个评测运行，逐例检查 improved、regressed、unchanged、added 与 removed，不能只看总通过率。

## 模型费用

内置 demo 不调用外部模型。启用真实模型前，应从实际提供商确认当前模型价格，配置 `AGENTTRUST_MODEL_INPUT_USD_PER_MILLION` 和 `AGENTTRUST_MODEL_OUTPUT_USD_PER_MILLION`（美元／百万 Token）。未配置时为 -1，拒绝付费模型调用；只有实际免费模型才填 0。

策略支持 `max_output_tokens`（默认 1024）、`max_cost_usd`（默认 0.25）和 `max_tool_calls`（默认 6）。发送前按文本字节数加消息开销保守估计费用，并限制输出 Token；完成后根据提供商 usage 和配置费率估算费用。它不是账单对账，也不是跨请求的硬性总预算；定价错误、非标准计费、供应商不遵守输出上限仍会影响费用。

当前真实模型适配仍是文本 Chat Completion，不是通用多步 Agent 编排器。多轮红队共享 AgentTrust 会话风险状态，但静态攻击脚本不能替代真实攻击模型或独立基准。

## 工具、退款和隐私边界

- 工具是注册的可信 Python Adapter，线程池最多四个执行槽。没有任意 Shell／代码上传入口，但也没有 OS 级隔离。超时仅停止等待，不能硬终止已运行线程；不要注册不可信插件。
- 工具参数在执行前检查；包含敏感原文、必须依赖凭据的参数会拒绝，而不是悄悄更改参数。模拟邮件改用 `recipient_id: customer_demo`，不接收邮箱地址。真实邮件／支付适配应由专门的凭据代理解析授权引用，本轮不实现真实发送或付款。
- 副作用工具即使被加入 allowed_tools，也仍要求一次性参数绑定租约。远程 MCP 租约必须绑定 `target: mcp:<server_id>:<manifest_hash>`，不能拿本地工具批准去调用另一个服务器。
- MCP 参数采用 Draft 2020-12 JSON Schema 校验；当前明确拒绝引用、动态引用和正则 Schema，限制深度与节点数，不对外下载 schema。支持范围不是完整 MCP 协议认证。
- 退款仅模拟。支持 CNY/USD/EUR 两位小数，内部以整数分预留余额。相同幂等键必须对应完全相同的请求；更换金额、订单、原因或证据返回 409。
- 退款在工具执行前原子预留，避免先执行后发现余额不足。执行异常进入 unknown，预留不释放，也不自动重发。进程在执行期间崩溃可能留下 settling；这些状态都需要确认工具实际结果后处理，不应手工改回 approved 后重试。本轮不提供真实支付查询、对账或补偿接口。
- 工作流在输入入库前脱敏，blocked 和 completed 分开记录。工具结果不明进入 unknown，禁止自动重试。一般模型失败仍保留手动重试入口，本地模式没有后台重试调度器。
- 已有数据库只增加列，不删除历史记录。新记录受新防护约束；旧版本曾写入的敏感原文不会被本次升级自动清理。处理旧记录需另行备份、确定范围并取得删除授权。

## 评测口径

主回归 30 条、合成 holdout 12 条；消除完全相同输入，记录数据集 SHA-256。它们仍属于少量、相关模板样本，不是独立真实世界盲测。候选生成不再直接复制评判器的整套攻击签名。

回放只评测 PolicyEngine。界面的评分／优先级是启发值，不能称为成功概率、安全准确率或完整 Agent 的效果。结果增加攻击召回置信下界与误报置信上界；高通过率不弥补样本不足。自动模式门禁仍属实验，不支持据此作生产准确率承诺。

投简历时可表述：实现运行时策略、参数绑定批准、原子副作用预留，以及经回归复核的人工策略发布与版本回滚；附合成场景、测试结果和未实现边界。

## 升级和回退

先停止正在使用的 API／worker，再启动新版本。SQLite 启动时会增加退款金额及幂等指纹列，不覆盖原有金额字段或删除数据。旧退款没有完整请求指纹，不能用旧键悄悄重新执行；使用新键前仍需确认旧请求结果。PostgreSQL 使用离线迁移，未在本轮真实环境验收。

代码文件回写前会单独备份。回退代码不等于撤销已经执行的业务动作；数据库新增列可保留，不建议通过删列回退。

验证：运行 `scripts/verify.ps1`。测试使用独立合成数据库并保留产物，不接触正常数据库；PostgreSQL 专用测试未配置服务器时仍会 skip，不能把这一状态解释为通过了生产隔离验收。

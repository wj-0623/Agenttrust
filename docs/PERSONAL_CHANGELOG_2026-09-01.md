# AgentTrust 个人版变更记录

## v0.9 Portfolio Release

- Step Guard 从四阶段扩展到 input、context、tool、tool_result、output 五阶段。
- 新增脱敏 Provenance Graph；父节点必须属于同一项目／会话，数据库仅保存内容哈希、标签和决策。
- 新增会话污点传播：不可信内容流向副作用工具强制审批，敏感来源流向出站工具直接阻断。
- 红队增加共享会话多轮策略、轮次上限、费用上限、随机种子、提前停止与逐轮 Trace。
- 评测和红队增加 `agenttrust.run-manifest.v1`；新增两次评测的逐例差异 API。
- 外部 Agent URL 白名单改为空默认值，移除对具体作品项目的运行时假设；与星限仅保留简历叙事关系。
- 控制台升级为 v0.9，红队页面显示多轮策略与实验结果哈希。

## v0.6 个人版修复记录

范围：根据 2026-08-31 评审修复个人使用的核心安全和运行问题。没有开展企业 SaaS 扩建，没有接入真实资金，没有删除项目文件、历史数据库或旧构建资源。

## 已实现

- 请求 JSON 媒体类型统一检查；缺少／不支持 Content-Type 的请求明确拒绝。认证后的密钥／成员请求使用调用者工作空间默认值，并增加服务层归属校验和组织归属检查。
- 无认证个人模式限制本机连接、Host 和 Origin；Vite 默认只监听环回地址。A2A 资产管理与消息发送的权限分开。
- 退款增加整数分余额和金额字段、完整业务请求指纹。相同键不同载荷返回冲突；原子预留先于工具调用；异常保留预留并标记 unknown，阻止自动重发。
- DLP 阻断结果用于退款决策；工作流入库前脱敏，blocked 不再记为 completed；通用工具拒绝敏感入参，模拟邮件使用 recipient_id。
- 工具结果、模型结构化工具调用均受输出处理；MCP 返回值增加指令检查。租约必须绑定参数和执行目标；副作用 Adapter 不因工具允许列表而跳过批准。
- 策略强类型校验、正则超时／错误拒绝、受限 JSON Schema 验证；可信 Adapter 执行槽限制为四个，明确不提供 OS 隔离或线程硬终止。
- 个人默认人工发布；审核重新验证主集、合成 holdout 和自定义集，禁止新增回归、放宽已有规则或改动保护字段。发布与回滚检查基线版本，不覆盖更新的策略。
- 消除 holdout 的两条完全相同输入；候选不再直接复制评判器全部签名；记录数据集指纹、评测范围和置信界，界面不再把启发值称为成功概率。
- 真实模型增加价格配置要求、单次费用预检和输出 Token 上限，不再固定报告零费用；Trace 增加策略指纹与模型快照。
- 控制台按视图取数、先获取可访问项目、处理空项目，并通过请求代次检查及清空状态防止凭证／项目切换时展示旧数据；补人工发布按钮。
- 提供 `examples/personal_client.py` 作为本地接入示例；更新 README、个人指南与旧面试文档的适用范围。

## 验证

- 完整 pytest：47 passed，3 skipped。新增个人安全回归文件包含媒体类型、租户默认值、顺序／并发退款、未知结果不重试、重复初始化保留余额、金额与幂等冲突、DLP、工作流阻断、工具超时限制、模型结构化返回、Schema／正则、人工发布冲突和费用预检。
- Ruff：通过；Bandit：通过。
- 前端 TypeScript 检查与 Vite 生产构建：通过，构建不清空旧资源。
- 浏览器：本机首屏、红队生成候选、人工发布、回滚、无效凭证下旧内容清空均验证。

## 保留边界

PostgreSQL 专用测试跳过，不代表生产租户隔离通过。没有验证真实 Temporal、支付对账、OIDC 生命周期、外部模型准确率、负载、灾备或异地审计。新增依赖未据本记录声明完成独立供应链审计。

AgentTrust 与其他作品项目保持仓库、部署和运行时隔离；本轮不修改任何外部项目。服务器可信会话身份、跨请求硬预算、强隔离执行、历史敏感记录清理、真实副作用对账尚未实现，也不会自动启用。历史库中的旧敏感原文未删除；如需处理，应另行确定范围并取得授权。

使用与升级步骤见 [PERSONAL_USE.md](PERSONAL_USE.md)。此前的企业版本文档保留为历史记录。

# Contributing

AgentTrust is maintained as a personal portfolio project, but focused bug reports and security improvements are welcome.

1. Open an issue describing the problem, expected behavior, and the smallest synthetic reproduction.
2. Create a branch from `main` and keep changes scoped.
3. Run `scripts/verify.ps1` before opening a pull request.
4. Add a regression test when behavior or a security boundary changes.
5. State security impact, migration impact, and any remaining limitation in the pull request.

Do not submit secrets, personal data, proprietary prompts, production traces, or working exploits against systems you do not own. Report vulnerabilities through the private process in `.github/SECURITY.md`.
